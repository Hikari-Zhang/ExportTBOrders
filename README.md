# 淘宝订单导出

把你自己已登录的淘宝「已买到的宝贝」导出成 Excel 或 CSV。一行一件商品，包含物流公司、运单号和最新一条物流。表格和日志只留在本机。

## 安装

1. `npm install`
2. `npm test`
3. `npm run build`
4. 打开 `chrome://extensions`，打开「开发者模式」，选择「加载已解压的扩展程序」，选这个项目里的 `extension` 目录。

## 使用

1. 用 Chrome 打开 https://buyertrade.taobao.com/trade/itemlist/list_bought_items.htm 并登录。
2. 页面右上角会出现「淘宝订单导出」悬浮窗。橙色标题栏可以拖动，点「—」可以收起。
3. 选择日期和订单状态。默认日期是最近 3 个月，状态默认全选。
4. 选择 Excel 或 CSV。需要把日志保存成文件时，勾选「下载日志」。不勾选则只在窗口里显示日志，不下载日志文件。
5. 点「开始导出」。导出过程中不要关闭这个订单页。
6. 完成后，表格会下载到浏览器的下载目录。勾选了「下载日志」时，还会下载 `淘宝订单_导出日志_时间.txt`。

遇到验证时，导出会暂停，订单页顶部出现提示。在页面上完成验证后，点「继续导出」。同一单如果仍读不到，会留下空的运单号并继续后面的订单。

也可以点浏览器工具栏里的扩展图标，使用同样的选项。

## 人工核对

导出最近 7 天，并勾选「下载日志」。对照订单页看商品行数，打开表格抽一笔已发货订单核对运单号。日志里要有「开始导出」、翻页记录、该订单的物流记录和「导出完成」。
